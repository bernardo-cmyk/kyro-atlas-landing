# KYRO ATLAS · Chiropractic & Athletic Science

Landing page de la clínica KYRO ATLAS: quiropráctica clínica, rendimiento atlético y sauna.

- Sitio publicado: https://quiropractico-landing.vercel.app
- Página estática de un solo archivo (`index.html`) con HTML, CSS y JavaScript sin dependencias.
- Bilingüe español / inglés (botón ES / EN; recuerda la elección).
- Modelo interactivo del cuerpo con 8 zonas, vista de columna y formulario de valoración (vista previa, todavía no envía datos).
- Blog con seis artículos basados en evidencia, en español e inglés. Cada artículo tiene su propio enlace (`#blog/<slug>`).

## Estructura

| Ruta | Contenido |
| --- | --- |
| `index.html` | El sitio completo |
| `marca/` | Logotipo y manual de marca |
| `versiones-anteriores/` | Diseños previos guardados como respaldo |

## Pendientes antes de publicar

Los textos marcados como **[PENDIENTE]** son datos del consultorio (nombres, cédulas, dirección, teléfono, precios, horarios). Los marcados como **[VERIFICAR]** son propuestas clínicas que deben confirmar los quiroprácticos.

## Publicar

El sitio se despliega en Vercel como proyecto estático (sin framework ni build). Basta con conectar este repositorio al proyecto `quiropractico-landing` en Vercel.
